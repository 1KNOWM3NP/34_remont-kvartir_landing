# AGENTS.md — 34_remont-kvartir_landing

Лендинг-воронка: ремонт квартир под ключ. Язык сайта — русский. Цель — лиды (заявки), оплаты нет.

## Стек
- Vite + React + TypeScript + Tailwind CSS v4 (`@tailwindcss/vite`)
- Запуск: `npm run dev` (http://localhost:5173), сборка: `npm run build`
- Заявки: `src/lib/api.ts` — абстракция (сейчас localStorage + заглушка отправки, позже SQLite-бэкенд без переписывания форм)

## Правила работы (обязательны в каждом чате)
1. Прочитай `ROADMAP.md` — там статусы задач. Работай только над текущей задачей.
2. Коммиты мелкие, после каждого шага: `git add -A && git commit -m "..." && git push`.
3. Сообщения коммитов — короткие, на русском или английском, по смыслу шага.
4. Визуальная проверка через Playwright MCP (запасной — chrome-devtools MCP): скриншот, клики по модалке/калькулятору, мобильный viewport 375px.
5. MCP включать только на время визуальной проверки, в кодовых чатах отключать (экономия контекста).
6. В конце чата: коммит + пуш + хэндовер из 3–5 строк (что сделано, hash, следующая задача).
7. Порог ротации: ~20% остатка контекста — фиксируемся и переходим в новый чат.
8. Дизайн: свобода, трендово (крупная типографика, тёплая палитра, bento-сетки). Иконки — только SVG, тач-зоны 44px, контраст 4.5:1, mobile-first.
9. Копирайтинг: конкретика вместо «качественно и недорого», один оффер на секцию.
